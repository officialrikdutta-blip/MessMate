# MessMate 🍱

### 🚀 Live Demo: https://messmate-i1so.onrender.com

Hostel students ke liye Mess Management System.

**Features:**
- 👨‍🎓 Student Login System
- 🍛 Today's Menu & Weekly Menu
- 🗳️ Daily Vote - Mess khaoge ya nahi?
- 💬 Feedback System
- 👑 Admin Panel - Menu update & Feedback dekho

**Login Details:**
- Student: `riya` / `riya123`
- Admin: `admin` / `admin123`

**Tech Stack:** Python Flask + MySQL (Aiven Cloud) + Render
